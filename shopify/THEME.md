## 1) Zip

```bash
./shopify/pack-theme.sh
```

→ `shopify/arzive-theme.zip` (också i Cursor Context docs)

## 2) Ladda upp

1. Admin → **Online Store → Themes**
2. **Add theme → Upload zip** → `arzive-theme.zip`
3. **Publish**
4. Customize → **Study with Arzive URL** → din Next `/study`
5. Skapa sida **Our story** (handle `our-story`)
