# Theme upload

1. Upload `arzive-theme.zip` → Publish.
2. Assign page templates: handle `our-story` → **page.our-story**, handle `pricing` → **page.pricing**.
3. Create membership products `membership-standard` / `membership-annual` / `membership-scholar` (see `shopify/products.md`), enable Shopify Subscriptions on them, then optional: Theme editor → Pricing section → pick those products. Re-upload the theme zip so Buy posts `selling_plan`.
